# ✦ PR TRACKER — README
 
**@3zantn 作・配布のPR案件＆プレキャン管理ツール**
 
---
 
## 📌 概要
 
PR案件・プレキャン応募の記録と、X収益化の進捗を一元管理できるブラウザアプリです。
データはブラウザのlocalStorageに保存されるため、外部への送信は一切ありません。
 
---
 
## 🚀 使い方
 
HTMLファイルをブラウザで開くだけで使えます。インストール不要。
 
---
 
## 🗂️ 主な機能
 
### 1. PR・プレキャン記録
- **種別**：PR案件 / プレキャン の2種類
- **記録できる内容**：ブランド名・商品名・応募日・ステータス・投稿期限・投稿済みフラグ・メモ
- **ステータス**：選考中 / 当選 / 落選
- カードビュー・テーブルビューの切り替え可能
### 2. 目標管理（Goalsタブ）
- フォロワー数の進捗バー（現在値と目標値を入力）
- X収益化インプレッション進捗（3ヶ月500万imp目標）
- 収益化条件チェックリスト（X Premium加入 / フォロワー500人 / インプ500万）
- フリーメモ欄
### 3. 統計バー
- 合計件数 / 当選数 / PR件数 / 投稿済み数 をヘッダーに常時表示
---
 
## 💾 データについて
 
- 保存先：ブラウザのlocalStorage（端末ローカルのみ）
- ブラウザのキャッシュ削除・シークレットモードでは**データが消えます**
- 定期的にスクリーンショット等でバックアップ推奨
